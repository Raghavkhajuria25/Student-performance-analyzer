# 📊 Student Performance Analyzer

> 🚀 **A growing Data Science project built step-by-step**

A Python-based student performance analysis project built using **NumPy**.

**Current Version:** `1.0 — NumPy`

---

## 📌 About

This project generates data for **50 students** and performs academic performance analysis using NumPy.

The project is designed to grow continuously as new Data Science and Machine Learning technologies are learned.

### 🔥 Project Evolution

**NumPy → Pandas → Matplotlib → Seaborn → Streamlit → Machine Learning**

---

## ✨ Features

- 👨‍🎓 Student data generation
- 🔎 Data filtering & conditional analysis
- 📊 Statistical analysis
- ✅ Pass/Fail classification
- 🏆 Top 5 & Lowest 5 students
- 📈 Performance categorization
- 🕐 Attendance & study-hours analysis
- 🧮 Weighted overall score
- 🎁 Attendance-based bonus
- 🧹 Missing-value handling
- 🔄 Reshaping, stacking & broadcasting
- ✖️ Dot product & matrix multiplication
- 📏 Score normalization
- 📑 Final performance report
